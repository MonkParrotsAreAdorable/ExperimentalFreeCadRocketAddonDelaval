The objective of this file is the demonstration of the Programatic ability of the team proposing the Astronautica project.
To this end , a simple module has been developed for the rocket addon.
This module generates the geometry of a De Laval taking inputs from the relevant equations.
With the geometry generated , a user can use it to run a boolean operation in a cooled housing for the final rocket nozzle engine.
Possible further developments are the design and development of an Aerospike nozzle workflow , or perhaps a thermal analysis workflow.
